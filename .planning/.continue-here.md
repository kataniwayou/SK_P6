## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Editing a processor's `Program.cs` changes its SourceHash identity | `Processor.Sample`/`Processor.BadConfig` fold **every** `.cs` in the project dir (incl. `Program.cs`) into the 64-hex SourceHash (`SourceHash.targets`). Adding a `--healthcheck` guard shifted `94ca171c→6cbf5688`, so the deployed processor no longer matched its seeded DB `processors.source_hash` row → liveness gate 422 → orchestration wouldn't fire. | blocking | NEVER add non-business code (healthchecks, arg-guards, infra) to `src/Processor.*/Program.cs`. Put such code in a NON-folded assembly (sibling like `Messaging.Contracts`, or the non-processor services). Already reverted in commit 6bb1f83. |
| Docker-Desktop k8s serves STALE `:local` on rebuild | Same-tag `:local` + `imagePullPolicy: IfNotPresent`: containerd imports a docker-built image into the `k8s.io` namespace only on FIRST deploy; a rebuilt same-tag is silently stale. | advisory | On a warm cluster, deploy under a unique tag: `docker tag x:local x:offline; kubectl -n skp set image deployment/x x=x:offline`. Fresh offline machine won't hit this. |
