<objective>
Port the compose `rabbitmq` (L161-176) and `elasticsearch` (L28-49) blocks to StatefulSets, each with a PVC and a `startupProbe` translating the compose `start_period` cold-start budget. rabbitmq +1Gi PVC (D-11); elasticsearch +2Gi PVC (D-10).
