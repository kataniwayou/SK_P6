<objective>
Build the mechanism that makes the whole phase possible: a reader that turns rendered Grafana
panels into numbers, and the PowerShell contract for calling it. Also register the requirement
family every later plan cites.

Locked constraint 2 says the rendered panel is the verdict. Nothing in this repo can read a
rendered panel today — there are zero `.js` files and no script invokes `node`. This plan closes
that, and nothing else. No cluster mutation happens here; both scripts are authored and statically
gated only. The live shake-out of the reader is plan 88-03's job (Wave-0 probe questions PQ-02
and PQ-04).

Purpose: without a trustworthy panel reader, every later assertion in the phase degrades to
"proving the query instead of the panel" — the exact Phase-87 defect this phase exists to avoid
(`87-FINDINGS.md` §12).
Output: `.planning/REQUIREMENTS.md` family block, `scripts/phase-88-panel-read.js`,
`scripts/lib/phase-88-panel-read.ps1`.

Sampling vocabulary used by the whole phase (fixed here, once):
  SAMPLE  = the value read from ONE 60-second-wide absolute pinned window (a stat panel's big
            number, or one legend row's Mean for a timeseries series).
  CAPTURE = N contiguous 60-second sub-windows covering an N-minute span. A DISC-01 baseline
            capture is N = 10; an after-capture is N >= 5 covering the fault.
  60 s is the stored resolution (the SDK export cadence, measured in Phase 87 §11), so a
  sub-window narrower than 60 s cannot yield an independent sample.

Reader invocation contract (PowerShell -> node -> Grafana):

  INPUT  (process environment, passed straight through by run.js):
    GRAFANA_URL        default 'http://127.0.0.1:3000'
    DASHBOARD_UID      default 'skp-business'
    PANEL_IDS          required, comma-separated, e.g. '9' or '1,2,3,4,5,9'
    WINDOWS            required, semicolon-separated absolute epoch-ms pairs 'from:to;from:to;...'
                       — every pair MUST be the same width; the reader refuses the batch otherwise
    VIEWPORT_W         default '1920'
    VIEWPORT_H         default '1080'
    LOCATOR_MODE       'viewpanel' (default) | 'headerwalk'
    PANEL_TITLES       required only when LOCATOR_MODE=headerwalk; comma-separated, positionally
                       aligned with PANEL_IDS
    SCREENSHOT_DIR     optional, MUST be absolute (run.js does process.chdir(__dirname));
                       one PNG per (panel, window) named panel-<id>-<fromMs>.png
    GRAFANA_BASIC_AUTH optional base64 'user:pass'; applied as an Authorization header when non-empty

  OUTPUT (stdout, ONE line per (panel, window) pair, after run.js's own banner lines — all pairs
  are read in a SINGLE browser session, because a 14-panel x 10-window baseline is 140 reads and a
  process launch per read would dominate the run):
    ##PANEL-JSON## {"panelId":"9","dashboardUid":"skp-business","fromMs":...,"toMs":...,
                    "windowWidthSeconds":60,
                    "viewportWidth":1920,"viewportHeight":1080,"url":"...",
                    "panelState":"Rendered"|"NoData"|"Error",
                    "rawText":"...","series":[{"name":"...","mean":0.4001,"max":0.4005}],
                    "statValue":0|null,"screenshotPath":"..."|null,
                    "readerVersion":"1","capturedUtc":"2026-07-28T12:00:00.000Z"}
    ##PANEL-BATCH-END## {"requested":140,"emitted":140}
                    exactly one, last — lets the caller detect a truncated batch instead of
                    silently banding on a partial sample set.

Grafana 12.3.9 selector literals (verified against the v12.3.9 source tag — the value genuinely
begins with the words `data-testid `):
    panel body/viz            'data-testid panel content'
    panel header by title     'data-testid Panel header <title>'
    legend row by series name 'data-testid VizLegend series <name>'
    panel error status        'data-testid Panel status error'  (fallback 'Panel status')
    loading indicator         'Panel loading bar'

PowerShell surface exported by scripts/lib/phase-88-panel-read.ps1 (dot-sourced, pure except
Invoke-PanelReadBatch):
    Get-PropertyNames        $Object                             -> string[]  (StrictMode-safe)
    Get-PinnedWindowSeries   -EndUtc -SubWindowSeconds -Count    -> ordered @{FromMs;ToMs;FromUtc;ToUtc}[]
    Invoke-PanelReadBatch    -PanelIds -Windows [-DashboardUid] [-ScreenshotDir] [-LocatorMode]
                                 [-PanelTitles]                  -> @{ Readings[]; Requested; Emitted;
                                                                       Complete; State }
                                 State is 'Ok' | 'Truncated' | 'Unreadable' | 'ReaderMissing'
    Get-PanelSamples         -Readings -PanelId [-SeriesName]    -> double[] in window order
    Get-PanelStates          -Readings -PanelId                  -> string[] in window order
    Get-PanelBand            -Values                             -> @{Low;High;Mean;Sigma;FloorApplied}
    Test-PanelMoved          -Band -AfterValues -AfterStates -Direction -MinConsecutive
                                                                 -> @{Moved;ConsecutiveSamplesOutside;Direction}
